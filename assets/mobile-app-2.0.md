# 모바일 애플리케이션 콘텐츠 접근성 지침 2.0 (요약)

> 국가표준 KS X 3253 「모바일 애플리케이션 콘텐츠 접근성 지침 2.0」의 **요약 레퍼런스**다(00-overview.md
> 확정 결정: "모바일 앱 참고" 범위 — 웹 검사 도구인 `swwa`는 네이티브 앱을 직접 검사하지 않는다).
> 원문 전재 금지(NFR-04) — 조항 번호·정확한 지침 문구는 **표준 원문으로 재확인 필요**
> (`needsVerification`). 이 문서는 KWCAG 2.2와의 대응 감을 잡기 위한 참고용 개요다.

## 개요

KWCAG 2.2가 웹 콘텐츠를 대상으로 하는 것과 달리, 이 지침은 **네이티브/하이브리드 모바일
애플리케이션**의 접근성을 다룬다. 구조는 KWCAG와 유사하게 **4원칙**(인식·운용·이해·견고) 아래
여러 지침·검사항목을 두는 형태를 따른다.

## 4원칙별 핵심 관심사(요약, 조항 번호 미확정)

| 원칙 | 모바일 앱에서 특히 중요한 항목(요약) |
|---|---|
| 인식의 용이성 | 아이콘·이미지의 대체 텍스트, 앱 내 텍스트 확대(시스템 글꼴 크기 반영), 명도 대비 |
| 운용의 용이성 | 터치 타깃 크기, 제스처(스와이프 등) 대체 수단, 화면 회전 대응, 알림·팝업의 접근성 |
| 이해의 용이성 | 일관된 내비게이션·레이블, 오류 안내, 폼 입력 도움 |
| 견고성 | 플랫폼 접근성 API(Android AccessibilityService·iOS UIAccessibility)와의 연동, 커스텀 위젯의 role/name 노출 |

## KWCAG 2.2와의 관계

웹뷰(WebView) 기반 화면은 KWCAG 2.2 검사항목·`swwa`의 정적/브라우저 엔진으로 상당 부분 점검할
수 있다. 네이티브 UI(플랫폼 고유 컨트롤)는 이 지침의 별도 기준을 따르며, 이 프로젝트의 자동 검사
도구(`check_html`·`audit_url`)는 다루지 않는다.

## 검증 필요 사항 (`needsVerification`)

- 정확한 지침·검사항목 번호 체계(웹 KWCAG의 "N.N.N"과 동일한지 여부)
- 표준 제정·개정 연혁 및 최신 개정판 발행일
- 국가표준 원문 열람 경로(공식 고시 URL)

## 출처

국립전파연구원(방송통신표준) 「모바일 애플리케이션 콘텐츠 접근성 지침 2.0」(KS X 3253). 원문 미대조
상태이며, 정확한 조항 인용이 필요할 때는 표준 원문을 우선한다.
