# 사용자 심사 체크리스트 (a11y-audit)

품질인증의 **사용자 심사**는 장애 당사자가 실제 과업을 수행해 성공률을 본다. 자동 검사·전문가
심사가 대체할 수 없다. `get_checklist`의 `scope=user-eval`로 이 목록을 도구에서 받을 수 있다.

> 아래는 감사 보고서의 "수동·사용자 심사 잔여"에 넣을 과업 예시다. 실제 인증 성공률 기준(100%)·
> 절차는 인증기관 공지로 재확인 필요.

## 시각 (스크린리더·확대)
- 스크린리더(NVDA/VoiceOver)만으로 로그인 폼 작성 — 각 필드 레이블이 낭독되는가 [7.3.2]
- 반복 메뉴를 건너뛰어 본문으로 바로 이동 [6.4.1]
- 이미지·아이콘의 의미가 대체 텍스트로 전달되는가 [5.1.1]
- 화면 200% 확대 시 콘텐츠 손실·가로 스크롤 없이 사용 가능한가

## 청각
- 소리를 끄고 자막만으로 영상 내용 이해 [5.2.1]

## 지체 (키보드·스위치)
- 마우스 없이 키보드만으로 전체 주요 과업 수행 [6.1.1]
- Tab 이동마다 현재 초점 위치를 시각적으로 확인 [6.1.2]
- 작은 버튼·촘촘한 컨트롤을 오작동 없이 조작 [6.1.3]

## 인지
- 입력 오류 메시지만 보고 무엇을 고칠지 이해 [7.3.1]
- 이전 단계 입력 정보를 재입력 없이 진행 [7.3.4]
- 인증 과정이 퍼즐·기억력에만 의존하지 않는가 [7.3.3]

## 보고서 반영
- 각 과업의 성공/실패와 관찰된 장벽을 기록.
- 자동 감사에서 `manual`로 남은 검사항목과 연결해 "무엇을 사람이 확인했는지" 명확히.
- 검사항목은 `6.4.1(2.4.1)` 형식으로 인용.
