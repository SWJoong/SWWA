# 웹 접근성 품질인증 안내 (kwcag-guide)

> 사람이 읽는 안내. 기계용 데이터는 `assets/certification.json`, 도구는 리소스 `swwa://certification`.
> **수치·조항은 `needsVerification` 상태다 — 인증기관 공지·법령 원문으로 반드시 재확인**한다.

## 근거
- 디지털포용법 제21조 관련(시행령 조 번호는 출처마다 상이하게 인용됨 — 원문 확인 필요).
- 표준: KWCAG 2.2(33개 검사항목).

## 심사·기준(재확인 필요)
- **전문가 심사**: 검사항목 준수율 95% 이상(추정 기준값).
- **사용자 심사**: 장애 유형별 과업 성공률 100%.
- **종합**: 두 심사 평균 90점 이상.
- **유효기간**: 약 1년(확인 필요).

이 수치들은 인증기관이 개정할 수 있으므로 릴리스마다 `certification.json`의 `verifiedOn`을 갱신하고
답변 시 "인증기관 공지로 재확인 필요"를 덧붙인다.

## 절차
신청 → 전문가 심사 → 사용자 심사 → 결과 통보·보완 → 인증 마크 부여 → 사후 관리.

## 인증기관(예)
- 한국디지털접근성진흥원(KWACC) — http://www.kwacc.or.kr
- 웹와치 — https://www.webwatch.or.kr
- 한국시각장애인연합회 웹접근성평가센터 (URL 확인 필요)

## 도구와의 관계
- `estimate_cert_readiness`는 여러 페이지 자동 검사 결과로 **준비도를 추정**할 뿐, 인증 통과를
  판정하지 않는다. `estimatedExpertRate`는 자동·보조 등급 항목만으로 계산한 추정치다.
- 자동 검사로 판정 못 하는 수동·사용자 심사 항목이 항상 남는다.
