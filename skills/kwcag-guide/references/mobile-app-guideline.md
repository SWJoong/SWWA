# 모바일 애플리케이션 콘텐츠 접근성 지침 2.0 (kwcag-guide)

> 요약 안내. 도구 리소스는 `swwa://mobile-app-2.0`(번들 `assets/mobile-app-2.0.md`). 조항 번호 등
> 정확한 인용은 표준 원문으로 재확인 필요(`needsVerification`).

## 범위
- 국가표준 KS X 3253. **네이티브/하이브리드 모바일 앱**의 접근성을 다룬다(웹 대상 KWCAG 2.2와 별개).
- `swwa`는 웹 검사 도구이므로 네이티브 UI를 직접 검사하지 않는다. 앱 내 **웹뷰**는 KWCAG 2.2·
  `check_html`/`audit_url`로 상당 부분 점검 가능하다.

## 구조(요약)
KWCAG처럼 4원칙(인식·운용·이해·견고) 아래 지침·검사항목을 둔다. 모바일에서 특히 중요한 관심사:
- 인식: 아이콘·이미지 대체 텍스트, 시스템 글꼴 크기 반영, 명도 대비.
- 운용: 터치 타깃 크기, 제스처 대체 수단, 화면 회전, 알림·팝업 접근성.
- 이해: 일관된 내비게이션·레이블, 오류 안내.
- 견고: 플랫폼 접근성 API(Android AccessibilityService·iOS UIAccessibility) 연동, 커스텀 위젯 role/name.

## 언제 언급하나
- 사용자가 앱 접근성을 물으면: 이 지침이 별도 표준임을 알리고, 웹뷰 부분은 `swwa`로 점검 가능함을
  안내한다. 정확한 조항·성공기준은 표준 원문 확인이 필요함을 덧붙인다.
